# Terra360 - HtmlTerra

> Projeto Terra360 da elisa30creative

## 🚀 Início Rápido

### Pré-requisitos
- Node.js 16+
- npm ou yarn

### Instalação

```bash
# Clonar repositório
git clone https://github.com/elisa30creative/Terra360.git
cd Terra360

# Instalar dependências
npm install

# Variáveis de ambiente
cp .env.example .env.local
```

### Desenvolvimento

```bash
npm run dev
```

Acesse `http://localhost:3000`

### Build para Produção

```bash
npm run build
npm run start
```

## 📁 Estrutura do Projeto

```
Terra360/
├── pages/              # Páginas Next.js
├── public/            # Arquivos estáticos
├── components/        # Componentes React
├── styles/           # Estilos CSS
├── package.json      # Dependências
├── tsconfig.json     # Configuração TypeScript
├── next.config.js    # Configuração Next.js
└── vercel.json       # Configuração Vercel
```

## 🌐 Deploy

### Vercel (Recomendado)

1. Conecte seu repositório GitHub ao Vercel
2. Deploy automático em cada push para `main`
3. URL de produção: https://htmlterra360.vercel.app

```bash
# Deploy manual
vercel
```
